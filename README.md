# La Varangue — Boutique Hôtel & Restaurant

Projet académique de développement web réalisé avec **HTML5, CSS3 et JavaScript**.

## Présentation

Cette version modernisée reprend le premier projet étudiant et le transforme en site vitrine responsive pour un boutique-hôtel et restaurant gastronomique à Antananarivo.

> **Note :** il s'agit d'une maquette académique/portfolio et non d'un site officiel de l'établissement mentionné.

## Fonctionnalités

- Navigation responsive avec menu mobile
- Section d'accueil avec hero image
- Présentation du restaurant
- Cartes d'hébergement
- Menu interactif par catégories
- Galerie photo avec lightbox
- Formulaire de réservation avec validation JavaScript
- Affichage dynamique de l'année dans le footer
- Design responsive téléphone, tablette et ordinateur

## Technologies

- HTML5 sémantique
- CSS3 (Grid, Flexbox, variables CSS, responsive design)
- JavaScript vanilla (DOM, événements, validation de formulaire)

Ouvrir `index.html` dans un navigateur, ou utiliser l'extension **Live Server** de VS Code pour une prévisualisation locale.
